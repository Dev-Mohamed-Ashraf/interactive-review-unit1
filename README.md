مراجعة تفاعلية بالأنيميشن لـ **ثانية ثانوي — الفصل الأول: تكنولوجيا المعلومات والمجتمع** (4 دروس، عربي + English).

| الدرس | المحطات | أبرز الأنيميشن |
|---|---|---|
| 1-1 تطور تكنولوجيا المعلومات | 10 | خط زمني · شريحة مور بتتضاعف · مشاكل مور واحدة واحدة · **حل مسائل مور على السبورة** · معمل مور · تجربة العربية والشخص (سحابة ضد حوسبة طرفية) · AR/VR · بِت/كيوبت |
| 1-2 كيف يعمل الذكاء الاصطناعي | 9 | دوائر AI⊃ML⊃DL⊃GenAI · مدرّب فلتر سبام · شبكة عصبية · ذكاء توليدي + هلوسة |
| 1-3 الذكاء الاصطناعي في الحياة والصناعة | 8 | موبايل بالخدمات الأربعة · 4 صناعات متحركة · شاطر/حذر · الصندوق الأسود |
| 1-4 القضايا الأخلاقية | 9 | محاكاة تحيّز ذكاء التوظيف (تفاعلية) · كاميرات المراقبة · XAI · مثلث المسؤولية · المبادئ الأربعة |

فيه كمان **25 فيديو حقيقي** (مونتاج بيتغيّر مع كل خطوة) و**5 صور حقيقية** مفتوحة الترخيص (ENIAC · Intel 4004 · رقائق السيليكون · Waymo · IBM Quantum) — المصادر في [docs/CREDITS.md](docs/CREDITS.md).

**ألعاب ونقاط:** ⭐ XP ومستويات (🌱→👑) و10 أوسمة 🏅 · 🤔 توقّع قبل كل تجربة · ⚡ تحدّي السرعة لكل درس · 🎯 خمّن عدد الترانزستورات · 🎓 شهادة باسم الطالب للطباعة · سحب الكروت بالصباع في أسئلة التصنيف.

كل درس = **طريق تفاعلي** من محطات: شرح بالأنيميشن ← أمثلة محلولة خطوة بخطوة ← تدريبات الكتاب ← كروت مصطلحات ← فكّر كمهندس ← امتحان الدرس (بدرجة ونجوم). وفي الآخر **تحدّي الفصل**: 20 سؤال عشوائي.

## تشغيله

**اللينك أونلاين:** https://dev-mohamed-ashraf.github.io/interactive-review-unit1/ — افتحه مرة بإنترنت ودوس 📥 «نزّل المراجعة للأوفلاين»، وبعدين يشتغل من غير نت (على الآيباد: مشاركة ⬆️ ← إضافة إلى الشاشة الرئيسية).

### أسهل طريقة (ويندوز)
انسخ الفولدر كله على اللاب (فلاشة أو مضغوط zip) وبعدين:
- **دبل كليك على `تشغيل على الكمبيوتر.bat`** → المراجعة تفتح في المتصفح. لو مفيش Python بيفتح `index.html` مباشرة وبرضه شغّال.
- **دبل كليك على `تشغيل للآيباد والموبايل.bat`** → بيطبع رابط تفتحه من الآيباد/الموبايل/الشاشة التفاعلية على نفس الواي فاي.

### على الكمبيوتر (بالأوامر)
```bash
python tools/serve.py
```
وافتح `http://127.0.0.1:8765`.

### على الآيباد / الآيفون / الشاشة التفاعلية (نفس شبكة الواي فاي)
```bash
python tools/serve.py 8765 --lan
```
هيطبع رابط زي `http://192.168.1.5:8765` — افتحه من Safari.
لتثبيته كتطبيق: زر **المشاركة ⬆️ ← إضافة إلى الشاشة الرئيسية**.

### أونلاين (الأفضل للطلاب)
الفولدر ده موقع ثابت (static) — ارفعه كما هو على أي استضافة مجانية (GitHub Pages / Netlify / Cloudflare Pages).
بعد أول فتح، **بيشتغل أوفلاين** تمامًا (Service Worker).

## أثناء الحصة
| الأداة | الوظيفة |
|---|---|
| ➡️ / Space / سحب الشاشة | الخطوة الجاية (كل ضغطة = سطر شرح جديد + أنيميشن) |
| ⬅️ | رجوع |
| Esc | رجوع لطريق الدرس |
| 🔊 اقرا بصوت | الجهاز يقرا كل سطر شرح بصوت أول ما يظهر |
| 🎡 عجلة الأسئلة | في صفحة كل درس: لِف العجلة ويطلع سؤال عشوائي للفصل |
| 🎬 وضع العرض | للشاشة التفاعلية/البروجكتور: المشهد يملا الشاشة والشرح يظهر شريط ترجمة تحته |
| 🖥️ وضع المدرس | يفتح كل المحطات ويسمح بالتخطّي بدون إجابة |
| ☀️/🌙 | ثيم فاتح للبروجكتور / داكن للشاشات |
| EN / ع | تبديل اللغة في أي لحظة |
| ⛶ | ملء الشاشة |

التقدّم والدرجات بيتحفظوا على الجهاز نفسه.
